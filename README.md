# 🛍️ E-Commerce SHOPPER – MERN Stack Application

A fully functional **E-Commerce Web Application** built using the **MERN stack** (MongoDB, Express, React, Node.js).  
The application supports product browsing, cart management, user authentication, order processing, and admin operations.  
Designed with a clean architecture and scalable folder structure for real-world usage.

---

## 🚀 Features

### 👤 User Features
- User registration and login using **JWT authentication**
- Browse all products with images, categories, and descriptions
- Add items to cart and manage item quantities
- Secure checkout and order placement
- View order history and order details
- Fully responsive UI for mobile and desktop

### 🛠️ Admin Features
- Add, update, and delete products
- Manage product inventory and pricing
- View all orders and update order status
- Dashboard for quick system overview
